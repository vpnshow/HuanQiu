### ¥8/月和 ¥22/月有什么区别？

**¥8/月是环球学生套餐 ¥96/年的原价折合价**，需一次支付全年费用，每月提供 60GB 流量，不支持按 ¥8 月付。`HQ66` 7 折生效后为 ¥67.20/年，折合 ¥5.60/月；`THEO66` 8 折适用且生效时为 ¥76.80/年，折合 ¥6.40/月。**¥22/月是环球轻享的月付标价**，每月提供 120GB 流量。两档均最多支持 3 台设备同时使用。

<a id="huanqiu-coupon-guide"></a>

### HQ66 与 THEO66 有什么区别，可以叠加吗？

`HQ66` 为**全场套餐 7 折码**，截至 **2026 年 11 月 30 日**，总发行量 **2000 份、先到先得**，每用户限使用一次、不可兑换现金，且不与其他优惠同时使用。`THEO66` 为**专属 8 折码**，适用套餐、付款周期及续费条件以结算页为准。根据 `HQ66` 的活动规则，两者不能叠加；实际优惠以结算时可用的优惠码及最终金额为准。

<a id="huanqiu-one-time-plans"></a>

### 按量包是不限时套餐吗？

按套餐说明，环球随行包与环球灵活包均为**购买后 365 天内有效**的按量包，分别提供 80GB、400GB 固定总流量，不按月清零，也不每月刷新额度。商品卡片上的“终身”标签与说明存在差异，购买前应确认有效期。

<a id="huanqiu-device-and-reset-rules"></a>

### 能同时连接多少设备，流量用完怎么办？

学生套餐、轻享、畅游、尊享分别支持 **3、3、5、10 台设备**同时使用；每月自动重置流量，也可按 **¥10、¥21、¥36、¥63/次**购买对应套餐的流量重置包。随行包与灵活包分别支持 **5 台、8 台设备**，使用固定总流量。
